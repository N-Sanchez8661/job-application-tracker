# AI Usage Documentation

## Tools Used
- ChatGPT (OpenAI) for generating Flask routes, SQL queries, HTML templates, and CSS.
- ChatGPT for debugging errors and developing the Job Match feature.

## Key Prompts
1. "Is this a good app.py?"
2. "Give me the fixed code."
3. "Can we change the colors to purple instead of blue?"
4. Asked ChatGPT for help implementing CRUD operations and calculating job skill match percentages.

## What Worked Well
- AI helped generate the initial CRUD routes for all four database tables.
- Helped connect Flask with MySQL and organize the application.
- Provided useful explanations when debugging Flask and HTML template issues.
- Helped implement the Job Match algorithm and customize the website design.

## What I Modified
- Configured the MySQL database and Flask environment on my Mac.
- Fixed duplicate Flask routes that caused an endpoint error.
- Adjusted the navigation bar placement across the HTML pages.
- Customized the website with a purple color scheme.
- Tested the CRUD operations and verified the Job Match calculations.

## Lessons Learned
- AI-generated code still needs to be tested and debugged.
- Breaking a project into smaller steps makes development easier.
- Understanding error messages helps identify problems faster.
- AI is useful for generating code, but integrating and testing everything is still important.
